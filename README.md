# Aman Kumar Rajak — Data Analyst Portfolio

A responsive, single-page portfolio website made with HTML, CSS, and JavaScript. No framework, install step, or server is required.

## Preview locally

Open `index.html` in a browser. Alternatively, run `python3 -m http.server 8000` from this folder and open `http://localhost:8000`.

## Publish for free with GitHub Pages

1. Create a new public repository named `aman-data-analyst-portfolio` (or use `amanrajak6203-commits.github.io` for a root website).
2. Upload **all files from this folder** to the root of the repository: `index.html`, `styles.css`, `script.js`, and `favicon.svg`.
3. Go to the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
5. Your link will usually be `https://amanrajak6203-commits.github.io/aman-data-analyst-portfolio/` or `https://amanrajak6203-commits.github.io/` if you used the root repository name. Publication is not performed by this download.

## Customize

- **Text & project cards:** edit `index.html`.
- **Theme, sizing, and layout:** edit `styles.css`.
- **Project filters, mobile navigation, copy email:** edit `script.js`.
- **Contact email:** replace `amanrajak6203@gmail.com` everywhere in `index.html`.
- **GitHub links:** these point to public repositories verified on GitHub when the site was created.
- **LinkedIn:** the exact profile URL has not been confirmed, so no speculative or broken LinkedIn link was added. Once available, add it to the nav/footer.
- **Resume:** a public downloadable resume was intentionally not included to avoid uploading personal details from an existing resume without review. You can add an address-free PDF later.
- **Charts:** graphical designs on the page are illustrations. Portfolio-project numeric callouts are sourced from project README details. Client outcomes are from the user's supplied resume.

## Files

- `index.html`: page markup, metadata, content, inline decorative SVG
- `styles.css`: responsive design, visual components, motion
- `script.js`: navigation, filtering, email copy, scroll indicator, small reveals
- `favicon.svg`: brand icon
